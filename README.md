# Box Shadow Generator 🎨

A responsive Box Shadow Generator built with HTML, CSS and JavaScript.

This tool allows users to generate CSS `box-shadow` properties visually, preview the effect in real time, manually adjust values, and instantly copy the generated CSS code.

## Features

- Live box-shadow preview
- Adjust horizontal and vertical offsets
- Control blur and spread radius
- Color picker with RGB conversion
- Opacity control
- Toggle inner shadow (`inset`)
- Edit values manually or with sliders
- Automatic value validation
- Copy generated CSS rules with a single click
- Responsive interface

## How to Run

Clone this repository:

```bash
git clone https://github.com/andre-schiavone/BoxShadowGenerator.git
```

Open the project folder:

```bash
cd BoxShadowGenerator
```

Then simply open `index.html` in your browser.

No additional dependencies or installation steps are required.

## How to Use

1. Adjust the sliders or type values manually.
2. Choose the shadow color.
3. Set the opacity.
4. Enable **Inner Shadow** if desired.
5. Preview the effect instantly.
6. Click the generated CSS code to copy it to your clipboard.
